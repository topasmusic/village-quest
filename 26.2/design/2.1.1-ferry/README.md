# Village Quest 2.1.1 Ferry Marker

This folder retains the editable source and transparency intermediate for the ocean-ferry marker introduced in `2.1.1 - Homesteads & Wayfinding`.

- `source/map_ferry_master_chroma.png`: generated master on a chroma background
- `transparent/map_ferry_master.png`: full-resolution transparent master
- runtime asset: `src/main/resources/assets/village-quest/textures/gui/ui/map_ferry.png`

The final marker was generated specifically for Village Quest with the built-in image generator, then chroma-keyed and reduced to a `48 x 48` nearest-neighbor runtime sprite. Existing Village Quest home, village, and caravan markers were supplied as style references.

Prompt summary: compact medieval trade ferry; dark-oak hull, restrained brass trim, teal guild pennant, small cargo, pale-blue water base; readable Minecraft-style pixel art; centered with no text.
