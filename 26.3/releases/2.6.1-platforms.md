**Village Quest 2.6.1 — Living Kingdoms**

A smoother journey through Living Kingdoms: more reliable Notice Posts, clearer quests and a better Quest Board.


## Fixes and improvements

- Reliable compact Notice Post fallback and retrofit, with protection for existing builds and removed boards.
- General recipe-book search, separate output entries and native plank ingredients.
- Quest Board timer positioning, title/scroll fixes and corrected terrain-map sampling.
- Adult-only village introductions, clearer building checks and all five village chapters explained in game.
- Revised English, German and Spanish quest instructions and material names.

**Minecraft 26.3 · Fabric + Fabric API · Java 25.** Back up existing worlds and match client/server versions.
